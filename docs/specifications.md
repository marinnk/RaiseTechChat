# 仕様のルール

機能一覧の各機能について、細かい動きを定義します。Slackの仕様を参考にしています。

## 認証

- パスワードは8〜64文字とする（使える文字は「入力のルール」を参照）
- アクセストークンの有効期限は15分、リフレッシュトークンの有効期限は14日とする
- アクセストークンはフロントエンドのメモリに置き、リフレッシュトークンは HttpOnly Cookie に保存する（JavaScriptから読めないようにして、XSSで盗まれないようにする）
- リフレッシュトークンは、アクセストークンの更新に使うたびに新しいものを発行し、使ったトークンは失効させる（盗まれたトークンを使える期間を短くするため）
  - 例：10:00 に発行したトークンAで 10:15 に更新すると、新しいトークンBが発行され、トークンAは使えなくなる
- アクセストークンの更新は、同じブラウザ内で1つずつ順番に行う（Web Locks API を使う）
  - 2つのタブが同時に古いトークンで更新を頼むと、遅いほうのタブが失効済みのトークンを送ってログアウトされてしまうため
  - 例：左のタブがトークンAで更新している間、右のタブは待つ。右のタブは、Cookie がトークンBに変わってから更新を頼む
  - 1つのタブの中で同時に更新が必要になった場合は、1回目の更新の結果を待って、それを使う
- サインアップ時のメールアドレス確認は行わない。登録したらすぐに使える
- メールはパスワードリセットでだけ送る。ローカル環境では Mailpit で受信して、ブラウザで確認する
- ログアウトすると、その端末のリフレッシュトークンだけを失効させる（他の端末はログインしたまま）
- パスワードリセットのリンクの有効期限は発行から1時間とし、1回だけ使える
- パスワードを再設定すると、すべての端末のリフレッシュトークンを失効させる

## ワークスペース

- 1人のユーザーが複数のワークスペースに所属できる
- ワークスペースを作成すると、作成者が `OWNER` になり、`#general` チャンネルが自動で作られる
- 招待リンクの有効期限は発行から30日とする。有効期限内なら何人でも使える
- 招待リンクは発行するたびに新しく作る。発行済みのリンクを無効にする機能は作らない
- フェーズ1では、ワークスペースから自分で抜けることはできない

## チャンネル

- 公開チャンネルには、ワークスペースのメンバーなら誰でも参加できる
- 非公開チャンネルには、そのチャンネルの参加者に追加してもらった人だけが参加できる
- 一度非公開にしたチャンネルは、公開に戻せない
- チャンネルの名前・説明は、そのチャンネルの参加者なら誰でも変更できる
- チャンネルの削除はフェーズ2で実装する（OWNER・ADMINのみ）
- 非公開チャンネルは、最後の1人も退出できる。参加者が0人になってもチャンネルは削除しない

### #general

- ワークスペースに参加したメンバーは、自動で `#general` に参加する
- `#general` からは退出できない
- `#general` は非公開にできない
- `#general` の名前は変更できない（説明は変更できる）

## ダイレクトメッセージ（DM）

- DMの人数は、自分を含めて9人までとする
- 相手を選ばずに、自分だけのDM（メモ用）を作れる
- DMからは退出できず、あとからメンバーを追加することもできない。メンバーを変えたい場合は新しいDMを作る
- DMを作った人のサイドバーにはすぐに表示する。相手のサイドバーには、最初のメッセージが届いたときに表示する
  - 例：田中さんが佐藤さんとのDMを作っただけでは、佐藤さんのサイドバーには表示されない。田中さんがメッセージを送ると表示される

## メッセージ

- 編集したメッセージには「（編集済み）」と表示する
- 削除したメッセージは画面から消える
- フェーズ2でスレッドを追加した後は、返信があるメッセージを削除すると「このメッセージは削除されました」と表示し、返信は残す
- チャンネル・DMに途中から参加した人も、参加する前のメッセージをすべて読める
- フェーズ1では、システムメッセージ（「〇〇さんが参加しました」「チャンネル名を変更しました」など）は表示しない

## 未読管理

- チャンネル・DMに参加した時点の最新のメッセージを既読にする。参加した後に届いたメッセージだけが未読になる
  - 例：メッセージが300件ある `#random` に参加した場合、未読は0件から始まる
- 開いているチャンネル・DMに届いたメッセージは、すぐに既読にする。ただし、ブラウザのタブが裏にあるときは、タブに戻ってきたときに既読にする
- 自分が送ったメッセージは未読に数えない。送った時点で、そのメッセージまで既読にする
- 削除されたメッセージは未読に数えない
  - 例：未読3件のうち1件が削除されると、未読は2件になる
- 既読にすると、同じユーザーの別の端末・タブの未読バッジもリアルタイムで消す
- 未読が100件以上の場合は、バッジに「99+」と表示する

## リアルタイム反映

次の変更は、WebSocketで関係する人の画面にすぐ反映する。

| 変更 | 反映する相手 | 画面の動き |
| --- | --- | --- |
| メッセージの送信・編集・削除 | チャンネル・DMの参加者 | 開いていればメッセージを追加・更新・削除する。開いていなければ未読バッジを更新する |
| 新しいDM（最初のメッセージ） | DMのメンバー | サイドバーにDMを追加する |
| チャンネルの名前・説明の変更、非公開化 | チャンネルの参加者 | サイドバーとチャンネル見出しを更新する |
| 非公開チャンネルへのメンバー追加 | 追加された人 | サイドバーにチャンネルを追加する |
| 既読 | 同じユーザーの別の端末・タブ | 未読バッジを消す |
| ロールの変更 | ロールが変わった人 | ロールによって表示するボタン（［非公開にする］など）を切り替える |
| ワークスペースの削除 | ワークスペースのメンバー | ワークスペース選択画面に戻し、「ワークスペースが削除されました」と表示する |

- WebSocketの接続時に、アクセストークンで本人確認をする。接続した後にアクセストークンの有効期限が切れても、接続は切らない
- チャンネル・DMの通知を受け取るときに、そのチャンネル・DMの参加者かどうかを確認する（参加していないチャンネルのメッセージを受け取れないようにする）
- 接続が切れた場合は自動で再接続する。再接続したら、サイドバー（未読件数を含む）と、開いているチャンネル・DMの最新のメッセージをAPIで取り直す

## 入力のルール

### 共通

- 入力チェックは、フロントエンドとバックエンドの両方で行う。フロントエンドは使いやすさのため、バックエンドは不正なリクエストを防ぐため
- 文字数は、PostgreSQLの `VARCHAR` と同じくUnicodeのコードポイント単位で数える
  - Javaでは `codePointCount`、TypeScriptでは `[...text].length` で数える（`length` は使わない）
  - 例：`👍` は1文字、`👨‍👩‍👧` は5文字と数える
- パスワード以外の項目は、前後の空白（半角・全角スペース、タブ、改行）を取り除いてからチェック・保存する
  - 例：`"　田中 太郎 "` は `"田中 太郎"` として保存する
  - 例：`"   "` は未入力として扱う
- 改行は、メッセージでだけ使える
- エラーは入力欄の下に表示する。送信したときにチェックし、エラーが出た後は入力するたびにチェックし直す

### メールアドレス

- 必須、255文字まで
- `@` の前後に文字があり、`@` の後ろに `.` を含む形式とする
- 英字は小文字に変換して保存する。`Taro@Example.com` と `taro@example.com` は同じメールアドレスとして扱う

### パスワード

- 必須、8〜64文字
- 使える文字は、半角英数字と半角記号（半角スペースを含む）とする。全角文字・絵文字は使えない
  - bcryptは72バイトまでしか扱えないため、1文字1バイトの文字に限って上限を64文字にする
- 前後の空白も取り除かない（入力したとおりのパスワードにする）
- 英字・数字・記号を混ぜることは必須にしない

### 表示名

- 必須、50文字まで
- 他のユーザーと同じ表示名でもよい

### ワークスペース名

- 必須、80文字まで
- 他のワークスペースと同じ名前でもよい

### チャンネル名

- 必須、80文字まで（先頭の `#` は含めない）
- 使える文字は、文字（日本語を含む）・数字・ハイフン `-`・アンダースコア `_` とする。スペースと、それ以外の記号は使えない
- 入力中に、スペースはハイフンに、英大文字は小文字に自動で変換する
  - 例：`Dev Team` と入力すると `dev-team` になる
- 同じワークスペース内で、同じ名前のチャンネルは作れない（変換後の名前で比べる）

### チャンネルの説明

- 任意、250文字まで
- 未入力の場合はNULLとして保存する

### メッセージ

- 必須、4000文字まで
- 空白と改行だけのメッセージは送れない
- 編集するときも同じルールでチェックする。編集で空にすることはできない（消したい場合は削除する）

### エラーメッセージの例

- 未入力：「〇〇を入力してください」
- 文字数オーバー：「〇〇は50文字以内で入力してください」
- 文字数不足：「パスワードは8文字以上で入力してください」
- 使えない文字：「チャンネル名に使えるのは、文字・数字・ハイフン・アンダースコアだけです」
- 重複：「このメールアドレスはすでに登録されています」
