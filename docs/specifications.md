# 仕様のルール

機能一覧の各機能について、細かい動きを定義します。Slackの仕様を参考にしています。

## 認証

- パスワードは8文字以上とする
- アクセストークンの有効期限は15分、リフレッシュトークンの有効期限は14日とする
- アクセストークンはフロントエンドのメモリに置き、リフレッシュトークンは HttpOnly Cookie に保存する（JavaScriptから読めないようにして、XSSで盗まれないようにする）
- ログアウトすると、その端末のリフレッシュトークンだけを失効させる（他の端末はログインしたまま）
- パスワードリセットのリンクの有効期限は発行から1時間とし、1回だけ使える
- パスワードを再設定すると、すべての端末のリフレッシュトークンを失効させる

## ワークスペース

- 1人のユーザーが複数のワークスペースに所属できる
- ワークスペースを作成すると、作成者が `OWNER` になり、`#general` チャンネルが自動で作られる
- 招待リンクの有効期限は発行から30日とする。有効期限内なら何人でも使える
- 招待リンクは発行するたびに新しく作る。発行済みのリンクを無効にする機能は作らない
- フェーズ1では、ワークスペースから自分で抜けることはできない

## チャンネル

- 公開チャンネルには、ワークスペースのメンバーなら誰でも参加できる
- 非公開チャンネルには、そのチャンネルの参加者に追加してもらった人だけが参加できる
- 一度非公開にしたチャンネルは、公開に戻せない
- チャンネルの名前・説明は、そのチャンネルの参加者なら誰でも変更できる
- チャンネルの削除はフェーズ2で実装する（OWNER・ADMINのみ）
- 非公開チャンネルは、最後の1人も退出できる。参加者が0人になってもチャンネルは削除しない

### #general

- ワークスペースに参加したメンバーは、自動で `#general` に参加する
- `#general` からは退出できない
- `#general` は非公開にできない
- `#general` の名前は変更できない（説明は変更できる）

## ダイレクトメッセージ（DM）

- DMの人数は、自分を含めて9人までとする
- 相手を選ばずに、自分だけのDM（メモ用）を作れる
- DMからは退出できず、あとからメンバーを追加することもできない。メンバーを変えたい場合は新しいDMを作る

## メッセージ

- 編集したメッセージには「（編集済み）」と表示する
- 削除したメッセージは画面から消える
- フェーズ2でスレッドを追加した後は、返信があるメッセージを削除すると「このメッセージは削除されました」と表示し、返信は残す
- チャンネル・DMに途中から参加した人も、参加する前のメッセージをすべて読める

## 未読管理

- チャンネル・DMに参加した時点の最新のメッセージを既読にする。参加した後に届いたメッセージだけが未読になる
  - 例：メッセージが300件ある `#random` に参加した場合、未読は0件から始まる
