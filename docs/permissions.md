# 権限表

ロールごとにできる操作を定義します。Slackの初期設定を参考に、学習用に簡略化しています。

## ロール

| ロール | 説明 |
| --- | --- |
| OWNER | ワークスペースの作成者。1つのワークスペースに1人だけ |
| ADMIN | OWNERが任命する管理者 |
| MEMBER | 一般のメンバー。招待リンクから参加した人は最初このロールになる |

- オーナー権限の譲渡は行わない
- ゲスト（一部のチャンネルだけに参加できるユーザー）は作らない

## 操作ごとの権限

| 操作 | OWNER | ADMIN | MEMBER |
| --- | --- | --- | --- |
| 招待リンクの発行 | ○ | ○ | ○ |
| 公開・非公開チャンネルの作成 | ○ | ○ | ○ |
| 非公開チャンネルへのメンバー追加 | ○ | ○ | ○ |
| チャンネルの名前・説明の変更 | ○ | ○ | ○ |
| 公開チャンネルの非公開化 | ○ | ○ | × |
| 非公開チャンネルの公開化 | × | × | × |
| チャンネルの削除（フェーズ2） | ○ | ○ | × |
| 自分のメッセージの編集・削除 | ○ | ○ | ○ |
| 他人のメッセージの編集 | × | × | × |
| 他人のメッセージの削除（フェーズ2） | ○ | ○ | × |
| ADMINの任命・解除 | ○ | × | × |
| ワークスペースの削除 | ○ | × | × |

- 非公開チャンネルへのメンバー追加と、チャンネルの名前・説明の変更は、そのチャンネルに参加している人だけができる
- 非公開チャンネルとDMは、ロールに関係なく参加している人だけが閲覧できる（OWNER・ADMINでも、参加していなければ閲覧できない）
