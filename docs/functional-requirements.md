# 機能一覧

実装が完了したらチェックを入れて、進捗管理に使います。フェーズ1（MVP）が一通り動く状態になってから、次のフェーズに進みます。

## フェーズ1：MVP

Slack風として最低限使える状態を目指します。スレッドや未読はテーブル設計に影響するので、この段階で後から追加できる形にしておきます。

**認証**

- [ ] サインアップ・ログイン・ログアウト
- [ ] パスワードリセット

**ワークスペース**

- [ ] ワークスペースの作成
- [ ] 招待リンクでのメンバー追加

**チャンネル**

- [ ] チャンネルの作成・参加・退出
- [ ] 公開／非公開の切り替え

**メッセージ**

- [ ] メッセージの送信・編集・削除
- [ ] WebSocketによるリアルタイム反映
- [ ] 過去メッセージの無限スクロール

**ダイレクトメッセージ（DM）**

- [ ] 1対1のDM
- [ ] グループDM

**未読管理**

- [ ] チャンネル・DMごとの未読バッジ

**管理者権限**

- [ ] ロール（オーナー・管理者・メンバー）の付与・変更
- [ ] 非公開チャンネルのアクセス制御

**セキュリティ**

- [ ] XSS対策（メッセージ表示時のサニタイズ）

## フェーズ2：Slackらしさを出す機能

- [ ] スレッド返信
- [ ] メンション（@ユーザー、@channel）とブラウザ通知
- [ ] 絵文字リアクション
- [ ] ファイル・画像のアップロード（プレビュー表示、S3連携）
- [ ] メッセージ検索（キーワード・チャンネル・送信者で絞り込み）
- [ ] オンライン状態と入力中インジケーター
- [ ] プロフィール（アイコン、表示名、ステータスメッセージ）
- [ ] 管理者によるメンバーの削除、他人のメッセージ・チャンネルの削除
- [ ] レート制限
- [ ] レスポンシブ対応・ダークモード

## フェーズ3：外部ツール連携

難易度の低い順に実装します。

- [ ] Incoming Webhook（外部サービスからチャンネルに投稿できるURLの発行）
- [ ] スラッシュコマンド（`/remind` など）
- [ ] Bot・OAuth連携（外部サービスとの双方向のやり取り）
